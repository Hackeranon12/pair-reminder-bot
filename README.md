# Pair Reminder Bot

Telegram-бот напоминаний о парах УлГТУ. Берёт расписание группы с time.ulstu.ru, хранит пользователей и раз в минуту рассылает напоминания. Только стандартная библиотека Python.

## Файлы
- `bot.py` — сам бот: отвечает на сообщения и рассылает напоминания
- `reminder.py` — разбор расписания и логика напоминаний
- `fetch_schedule.py` — загрузка расписания с time.ulstu.ru

## Запуск
Создай `.env` рядом с файлами:
```
TELEGRAM_TOKEN=токен_бота
LK_LOGIN=логин_ЛК
LK_PASSWORD=пароль_ЛК
```
```bash
python3 bot.py
```
